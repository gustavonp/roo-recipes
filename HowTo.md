# Note for Aniki:

run local by running `hugo server`

## Special notes
- Make sure to run `npm uninstall -g sass` (newer Hugo uses embedded and it conflicts)
- When cloning, add `--recurse-submodules` flag, so it's `git clone --recurse-submodules https://github.com/gustavonp/roo-recipes.git`
- By default, it launches in your 127.0.0.1 port `1313`
